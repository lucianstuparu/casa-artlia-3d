# Source material

The original ERP plans and photographs are included here so geometry can be revisited while iterating on the private model.

- ERP source folder: https://drive.google.com/drive/folders/1BHYbGG0kDveUCYCFL33CF1Bk_rL4vC0_
- Photo folder: https://drive.google.com/drive/folders/10rH8jbg-Uw-wkw7p1ta1iAuvNbpBhbjl
- `plans/erp_avant.pdf` and `plans/erp_apres.pdf`: original two-page documents. Page 1 is RDC; page 2 is R+1.
- `plans/previews/`: the exact four plan raster previews embedded by the builder.
- `plans/extracted/`: supplementary extracted text; inspect the original pages for dimensions and layout.
- `photos/`: all 17 downloaded original photographs/screenshots. `sources.json` maps each filename to its original Drive source.
- `photo-references.json`: seven selected photo previews, observations and source links embedded in the offline model. It contains no signed download credentials.

The filing date was given by the user as 19 May 2026; the Drive modified date observed during reconstruction was 18 May 2026. Both remain distinct in the data. The v11 model was preliminary and was not available locally as HTML; no v11 geometry was imported as verified.
